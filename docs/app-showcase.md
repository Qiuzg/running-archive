# 手机 App 展示页

## 入口与维护

- 顶部 `App` 入口直接进入 `journal.html`，默认阅读图文开发历程。
- `app.html`：次级功能与界面页，通过 App 内容导航或手记末尾进入；保留功能介绍、分享图和常见问题。
- `journal.html`、`src/journal.css`、`src/journal.js`：独立图文开发手记，八章正文、目录定位、配图放大、深浅主题与打印样式。
- `src/app-showcase.js`：六组功能内容、截图索引、图片预览与主题切换。主题沿用网站的 `theme` 本地偏好，不导入地图、Chart.js 或 API 模块。
- `src/app-showcase.css`：桌面与窄屏布局、深浅色、键盘焦点及减少动态效果设置。
- `assets/app-showcase/*.jpg`：可发布的图片副本。Vite 的 publicDir 为 `assets`，运行时路径为 `BASE_URL + app-showcase/文件名`。
- Vite 同时构建 `index.html`、`app.html` 与 `journal.html`。开发预览访问 `/app.html`；既有部署脚本设置 `/run/` 时自动生成 `/run/app.html`，不需要新增服务端接口。

开发用 `npm run dev`，生产构建用 `npm run build`。检查子目录部署用 `BASE_PATH=/run/ npm run build`。

时间线依据 `ios/RunningArchiveSync/MOBILE_CLIENT.md`、iOS README 和此前开发聊天记录整理。更新功能时同时更新页面说明、截图说明与页尾日期。保持公开展示的事实边界：尚未上架，不提供虚假下载按钮；手表系统投递与运动提醒仍待配对真机验证。

## PC 端后续优化（2026-10-19 已实现）

下列优化已在后续开发中实现，详见 [PC 端优化记录](pc-refinements.md)：

1. 路线检索：现有筛选只有距离类型；已加入月份、城市和关键词组合检索，降低大量历史记录的检索成本。
2. 导航语义：目前“汇总”实际对应长距离轨迹集，已改为“路线集”，与“统计”区分。
3. 桌面布局：现有基础侧栏宽 380px，地图为全屏主体。路线适合继续用地图与列表联动；年度统计已改为独立宽版的图表与记录布局。
4. 回顾能力：在现有年度跑量上补充同阶段同比、月度日历和 PB 里程碑，优先回答自己的训练如何变化。
5. 加载与可访问性：改善按模块重试、加载反馈和图表键盘访问。新增介绍页已独立于地图与 API 加载。
